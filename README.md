# Woufy 🎵

Офлайн-плеер для iOS (Expo SDK 58): монохромный минималистичный интерфейс с мягким «жидким стеклом».

## Музыка
Приложение само создаёт папку **Music** (Файлы → На iPhone → Woufy → Music). Кладите туда файлы или целые папки
(mp3, m4a, aac, wav, flac, aiff) — сканируется всё вложенное. При возврате в приложение библиотека обновляется сама,
либо потяните список очереди вниз.
> В Expo Go папка недоступна из «Файлов» (песочница Expo Go) — работает в собранном .ipa / dev-билде.

## Тексты песен
Приоритет источников: SYLT (в тегах) → `.lrc` рядом с треком (то же имя) → LRC-метки в USLT → обычный текст (приблизительно).
Для обычного текста: Текст → «Разметить точно» → жмите «Метка» в начале каждой строки; результат сохранится в `.lrc`.

## DJ-склейка
За X секунд до конца A стартует B (громкость 0): A затухает 100→0%, B нарастает 0→100% одновременно (equal-power, S-кривая).
Темп: общий BPM линейно идёт от BPM A к BPM B (×½/×2 при кратном темпе). A ускоряется/замедляется, B стартует с темпом A и сходится к своему.
Биты: для каждого трека определяется сетка битов (BPM + фаза; два фрагмента — у начала и конца, темп уточняется до сотых).
B заранее загружается и встаёт на свой бит, стартует на бите A (по возможности — начало такта), далее фазу подруливает PLL.
Анализ идёт беззвучным «разведчиком» и приостанавливается на время склейки. Пока сетка трека не готова — подгон только по темпу.

## Тексты: источники
SYLT → .lrc рядом → кэш → LRC в USLT → онлайн LRCLIB (по названию/артисту/длительности; сохраняется в кэш и .lrc) → обычный текст.

## Запуск
```bash
npm install
npx expo start -c
```
