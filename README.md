## ✨ Ключевые возможности

### 🎛 Студийные звуковые эффекты (`modules/woufy-fx`)
Аппаратно ускоренная обработка звука на базе нативного **`AVAudioEngine`**:
* **Соборная реверберация (Cathedral Reverb):** Глубокое объёмное эхо с плавной регулировкой от 0 до 100% и автоматической компенсацией громкости.
* **8D Spatial Audio:** Кинематографичное перемещение звука по панораме ($\pm 0.95$, период 8 с) с эффектом присутствия в концертном зале.
* **Slowed + Reverb:** Мягкое виниловое замедление без цифровых артефактов и скачков высоты тона.
* **Speed Up:** Плавное ускорение темпа без потери разборчивости вокала.

### 🎚 Интеллектуальная DJ-склейка и синхронизация BPM
* **Equal-Power Crossfade:** Бесшовный переход между треками по нелинейной S-образной кривой без провалов по громкости.
* **Фазовый захват битов (PLL):** Автоматическое нахождение ударов бочки и выравнивание треков по сетке тактов до сотых долей секунды.
* **Бесшовный переход темпа:** Однократный превентивный подгон скорости в AVPlayer либо абсолютно непрерывная смена темпа в нативном `AVAudioEngine`.

### 📳 Music Haptics v2 (Core Haptics)
* **Адаптивный Taptic Engine:** Тактильный отклик, превращающий iPhone в виброакустический сабвуфер.
* **Трехслойная тактильная картина:**
  * **Бас:** Непрерывный низкочастотный гул с плотными толчками на дропах и бочке.
  * **Снейр:** Острые, сухие щелчки с регулируемой резкостью.
  * **Верха и вокал:** Деликатная бархатная микротекстура.
* *Два независимых тактильных канала (DualSense-style).*

### 📜 Синхронизированные тексты песен (Karaoke LRC)
* **Многоуровневый поиск караоке:** Встроенные теги ID3v2 `SYLT` $\to$ внешний файл `.lrc` в папке $\to$ кэш приложения $\to$ тег `USLT` $\to$ поиск в базе **LRCLIB**.
* **AI-выравнивание вокала (On-device Speech Recognition):** При отсутствии таймингов локальный `Speech.framework` распознаёт вокал в треке и автоматически расставляет временные метки.
* **Ручная микрокалибровка:** Долгое нажатие на строку песни в плеере для мгновенной подстройки таймингов под дыхание артиста.

### 🌊 Живой спектроанализатор (FFT Waveform)
* 20 полупрозрачных градиентных полос, реагирующих на реальный частотный спектр трека в 60 FPS.
* Динамическая прозрачность и плавный отклик без блокировки интерфейса.

## 📂 Организация библиотеки и файлов

Приложение создаёт чистую папку в iOS:
```
Файлы → На iPhone → WouFY.no → Music
```

| Директория / Путь | Назначение |
| :--- | :--- |
| **`.../Music/`** | **Только ваши аудиофайлы и альбомы.** Сканируются все вложенные папки. |
| **`.../Music/Track.lrc`** | Синхронизированный файл текста (рядом с `Track.mp3` с тем же именем). |
| **`Library/Application Support/WouFY/`** | Кэш метаданных, сохранённые тексты, обложки и состояние плеера (папка Music никогда не засоряется!). |

### Поддерживаемые форматы
* **Lossless / Hi-Res:** FLAC (включая 24-bit / 96kHz), ALAC, WAV, AIFF.
* **Compressed:** MP3, AAC, M4A.
* **Метаданные:** ID3v1, ID3v2.2, ID3v2.3, ID3v2.4, Vorbis Comments (FLAC), MP4 Atoms (M4A).

> [!TIP]
> При добавлении сотен новых треков библиотека загружается мгновенно: файлы появляются в очереди за доли секунды, а обложки и теги дочитываются в фоне без подвисаний.

## 🛠 Сборка и установка (.ipa)

Нативные функции (реверберация, 8D, Core Haptics и нативный анализ BPM) требуют скомпилированного бинарного файла, так как стандартный **Expo Go не поддерживает сторонние нативные модули**.

### Вариант 1: Готовая облачная сборка через GitHub Actions (Рекомендуется)
1. В репозитории откройте вкладку **[Actions](../../actions)**.
2. Выберите workflow **Build iOS IPA** $\to$ нажмите **Run workflow**.
3. Дождитесь завершения сборки (~5 минут) и скачайте артефакт **`woufy-ipa`**.
4. Установите `.ipa` на iPhone:
   * **Linux:** через установленный в систему **`iLoader`** (введите в терминале `iloader` или запустите ярлык из меню приложений).
   * **Любая ОС:** через **AltStore**, **Sideloadly**, **TrollStore** или **SideStore**.

### Вариант 2: Локальная сборка на Mac
```bash
# Клонирование и установка зависимостей
git clone https://github.com/woutype/WouFY.no.git
cd WouFY.no
npm install

# Генерация нативного проекта iOS и установка CocoaPods
npx expo prebuild --platform ios --clean
cd ios && pod install --repo-update && cd ..

# Запуск прямо на подключенном iPhone
npx expo run:ios --device
```

## ⚡ Быстрый старт разработчика

```bash
# Установка зависимостей
npm install

# Проверка типов
npx tsc --noEmit

# Проверка сборки бандла
npx expo export --platform ios

npx expo start -c
```

## 🏛 Архитектура проекта

```
WouFY.no/
├── App.tsx                     # Корневой контейнер, сессии, глобальные состояния
├── modules/
│   └── woufy-fx/               # Нативный модуль на Swift & AVAudioEngine
│       ├── ios/
│       │   ├── WoufyFXModule.swift # Мост Expo Module
│       │   ├── FXPlayer.swift      # Плеер с реверберацией, 8D и Time-Pitch
│       │   ├── HapticsEngine.swift # Двухканальный движок Core Haptics
│       │   ├── SpeechAligner.swift # Распознавание речи через Speech.framework
│       │   └── Analyzer.swift      # Офлайн-анализ сетки битов и спектра
│       └── index.ts            # Типизированный JS API с fallback-режимом
├── src/
│   ├── components/             # Компоненты UI (Queue, Player, Lyrics, Waveform)
│   ├── hooks/                  # Хуки контроллера аудио и жизненного цикла
│   ├── services/
│   │   ├── audioEngine.ts      # Диспетчер воспроизведения, кроссфейда и очередей
│   │   ├── fxPlayer.ts         # Адаптер нативного плеера эффектов
│   │   ├── musicHaptics.ts     # Обработка тактильных импульсов в реальном времени
│   │   ├── lyrics.ts           # LRCLIB API, парсинг и сохранение текстов
│   │   ├── id3Parser.ts        # Быстрый бинарный парсер метаданных
│   │   └── fileScanner.ts      # Высокопроизводительный асинхронный сканер файлов
│   ├── layout.ts               # Адаптивные метрики экранов iPhone
│   └── theme.ts                # Монохромная палитра и типографика
```
