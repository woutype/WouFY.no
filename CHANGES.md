# WouFY.no — что изменено

## Исправления
- **Подгон BPM при склейке**: смена скорости больше не пересобирает конвейер time-pitch на каждом шаге (качество `high` задаётся один раз, шаги редкие и крупные), убраны перемотки посреди перехода, PLL только мягко подруливает скорость. Фоновый анализ BPM приостанавливается перед склейкой и во время неё (раньше после первой склейки он возобновлялся прямо во время игры).
- **Нет звука / экран блокировки / Dynamic Island**: режим сессии `mixWithOthers` → `doNotMix` (в режиме «смешивания» iOS не показывает Now Playing), `play()` стартует только после активации сессии, сессия восстанавливается при возврате в приложение; убран `setCategory('Playback', true)` из volumeService.
- **Обложки по бокам на паузе**: соседние обложки полностью прозрачны в покое.
- **Волна**: затемнение обложки лёгкое (без размытия), новая отрисовка (28 полос от нижней линии, градиент), 60 fps (rAF + сглаживание по времени кадра), едет вместе с обложкой при смене трека.
- **Очередь**: перестановка и сброс сдвигов — одним кадром (нет «дёрганья» 0.5 с), плавная автопрокрутка у краёв с учётом мини-плеера.
- **Папка Music**: сканируется только Music. Служебные данные (состояние, кэш, тексты, обложки) — в Library/Application Support/WouFY. Файл-подсказка и lyrics_cache в Documents удаляются/переносятся, аудио из корня Documents переезжает в Music.
- **Фильтры**: плавное меню (поверх списка), убраны «Все / С текстом / Hi-Res», при активном фильтре — только его название и одна кнопка «Сбросить»; «По умолчанию» теперь реально возвращает прежний порядок; корректные сортировки (натуральная, А–Я, альбом: диск → номер трека).
- **Настройки**: убрана вкладка «Текущий трек», «Библиотека» — последней, «Обновить» показывает прогресс и итог.

## Новое
- Тумблер «Тактильный отклик под музыку» (onset-детектор баса/ударных по PCM-семплам, адаптивный порог).
- Тумблер «Включить звуковые эффекты»: реверберация (ползунок), 8D, Slowed (+ Reverb с ползунком), Speed Up. Реверберация и 8D — нативный модуль `modules/woufy-fx` (AVAudioEngine). Если модуль не соберётся — удалите папку `modules/woufy-fx`: приложение работает без него (останутся Slowed/Speed Up).
- BPM: три окна анализа + МНК по моментам битов, привязка к «круглым» значениям; теги BPM в файле приоритетнее.
- Текст: умный поиск в LRCLIB (кандидаты оцениваются по длительности/названию/артисту), если в базе нет — текст из файла (SYLT/USLT/LRC, а также FLAC и M4A), оценка таймингов по слогам с вступлением/аутро.
- Теги FLAC (Vorbis, PICTURE) и M4A (MP4 atoms), ID3v2.2, номер диска.
- **Мгновенная библиотека**: список файлов показывается сразу (имена файлов), теги и обложки дочитываются в фоне пачками.
- Название приложения: WouFY.no.

# Вторая итерация

- **Очередь, «телепорт» трека**: перетаскиваемая строка теперь рисуется оверлеем, соседи расходятся вживую (LayoutAnimation), при отпускании оверлей садится ровно в слот и исчезает одним кадром. Раньше нативная анимация и перестановка списка применялись в разные кадры.
- **Подгон BPM**: темп теперь меняет нативный AVAudioEngine (time-pitch), а не AVPlayer — без рывков. Шаг обновления 45 мс. Без нативного модуля остаётся прежний режим AVPlayer.
- **Реверберация**: пресет «собор», шкала 0–100 → до ~92% обработанного сигнала (слышна уже на малых значениях), с компенсацией громкости. 8D всегда идёт с лёгкой реверберацией (эхо зала).
- **8D**: звук перетекает из уха в ухо (панорама ±0.95, период 8 с), работает и на колонках.
- **Тактильный отклик**: Core Haptics (нативный модуль) — «толчки» на сильных ударах, transient с разной резкостью, непрерывный гул баса по огибающей, тонкие щелчки на хай-хэтах. Без модуля — fallback на expo-haptics (Heavy/Medium/Rigid + Warning).
- **Визуализация**: семплирование expo-audio слетало при смене трека и не подключалось при первом запуске — добавлены переустановка и повторные попытки; пока семплов нет, волна продолжает «дышать». Низкие частоты слева, высокие справа.
- **Очередь**: на обложке играющего трека мини-эквалайзер (на паузе столбики опускаются в точки).
- **Текст из файла**: если название в базе записано иначе, песня ищется по совпадению текста; тайминги растягиваются под вашу длительность; для приблизительного текста — долгое нажатие на строку «вот здесь её поют» подстраивает и сохраняет тайминги.
- **Настройки**: строка статуса нативного движка эффектов.

# Третья итерация (по видео)

**Видео 1 (очередь).** После отпускания строка на 2 кадра «улетала» на место соседа (тексты двух треков накладывались), затем возвращалась. Это рассинхрон нативной анимации и перестановки списка; новая схема (оверлей + живая перестановка) исключает его.

**Видео 2 (BPM).** В записи звука есть цифровые провалы: два длинных (~220 мс) на старте второго трека и серия по 30–60 мс примерно каждые 0.8 с на протяжении всей склейки. Причины и исправления:
- AVPlayer перезапускает конвейер time-pitch при каждой смене скорости → в режиме без нативного модуля используется *varispeed* (смена скорости без перезапуска конвейера), качество коррекции тона больше не передаётся на каждом шаге;
- при наличии нативного модуля подгон BPM идёт через AVAudioEngine (плавная смена темпа);
- фоновый анализ BPM запускал дополнительные плееры во время игры и мешал основному (провалы на старте склейки). Теперь анализ офлайн-нативный (читает файл напрямую, без плееров, в десятки раз быстрее, 5–6 окон по всему треку для регрессии темпа); в запасном режиме анализ работает только когда музыка остановлена.

# Четвёртая итерация

- **Визуализация и мини-эквалайзер «под обложкой»**: в React Native 0.88 стиль `StyleSheet.absoluteFillObject` удалён, поэтому слои, которые должны лежать ПОВЕРХ обложки, оказывались в обычном потоке — под ней (поэтому волна не появлялась, а эквалайзер в очереди висел под обложкой). Заменено на явный absolute-стиль.
- **Тактильный отклик v2** (Music Haptics / DualSense): три слоя — бас (непрерывный гул + «толчок» на сильных ударах), снейр (чёткий щелчок), верха/вокал (тонкая текстура); относительно громкости самого трека, привязка к сетке битов, лимитер плотности. Два независимых канала Core Haptics (как два мотора).
- **Текст без таймингов**: тайминги подгоняются по голосу в самом треке — нативное распознавание речи (Speech.framework, на устройстве где возможно) + выравнивание слов с вашим текстом + интерполяция по слогам. Результат сохраняется. При первом запуске iOS спросит разрешение на распознавание речи.
- **Диагностика** в настройках (модуль найден / движок включён / последняя ошибка) — чтобы было видно, работает ли нативный движок реверберации.
